# LACERA Overview

LACERA = **Los Angeles County Employees Retirement Association**. This is the pension
system for Los Angeles County employees, including **Los Angeles County Sheriff's
Department** personnel. Sheriff's Department members are **Safety** members (Safety
Plan A, B, C, or D depending on hire date), as opposed to General members.

LACERA administers both the **retirement (pension) benefit** and **retiree healthcare**
for LA County retirees.

### What to have ready when calling for a login

LACERA does not publish its registration field list on the public site, so this is not
confirmed — but expect them to ask for identity items in this range. Have all of it on
hand before dialing:

* Full legal name as it appears on the pension
* Social Security number (or LACERA member/employee number if known)
* Date of birth
* Mailing address on file with LACERA
* An email address to attach to the account (My LACERA signs in with **email +
  password**, not a member number)

**Open item:** confirm with the call center whether registration can be completed
entirely online or whether LACERA mails a registration/PIN code to the address on file.

## 3. What can be downloaded from My LACERA

Once logged in, My LACERA is a 24/7 secure account and message center. Retired members
can view and download:

* **Annual Benefit Statement** — mailed/posted in the month following the member's
  birthday. Shows personal member data, contributions on deposit, service credit, and
  named beneficiaries.
* **1099-R tax forms** — annual pension tax form.
* **Automatic Deposit Receipts (ADRs)** — the direct-deposit equivalent of a paystub;
  shows deposit amount, withholdings, deductions, and allowances.
* **Paystubs** — statement of earnings for the monthly benefit payment.
* **Pension verification letters** — proof-of-income letters for lenders, landlords,
  senior housing applications, etc.
* **Pathways / Spotlight newsletters**

There is also a **paperless opt-in** inside My LACERA: turn it on and the annual benefit
statement, ADRs, 1099-Rs, and newsletters are delivered electronically to the account
instead of by mail. Turning this on is what makes everything reliably downloadable
year-round.

Self-service transactions available in the portal include updating address and contact
info, tax withholding changes, direct deposit changes, beneficiary designations, and
uploading documents to LACERA.

## 4. Where downloaded statements are saved

All statements pulled from My LACERA are stored locally in this repo, under:

```
~/BGit/Bryan_git/tom_bryan/retirement/lacera/statements/
```

Directory layout (already created):

```
statements/
├── annual_benefit_statements/     # Annual Benefit Statement PDFs
├── 1099R_tax_forms/               # 1099-R pension tax forms, one per tax year
├── deposit_receipts_ADR/          # Automatic Deposit Receipts / monthly paystubs
└── pension_verification_letters/  # Proof-of-income letters
```

**File naming convention** — use the year (and month where monthly) first so files sort
chronologically:

| Document | Filename pattern | Example |
|---|---|---|
| Annual Benefit Statement | `YYYY_Annual_Benefit_Statement.pdf` | `2026_Annual_Benefit_Statement.pdf` |
| 1099-R | `YYYY_1099R.pdf` | `2025_1099R.pdf` |
| ADR / paystub | `YYYY-MM_ADR.pdf` | `2026-06_ADR.pdf` |
| Pension verification letter | `YYYY-MM-DD_Pension_Verification_Letter.pdf` | `2026-07-27_Pension_Verification_Letter.pdf` |

> These are sensitive financial documents containing SSN-adjacent data. Confirm whether
> this repo is private before committing any downloaded PDFs; if it is public or shared,
> keep `statements/` in `.gitignore` and store the files in the Large File Bridge
> private repo instead.
